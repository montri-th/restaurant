# CityMETER: Restaurants

**ร้านอาหารแน่นที่สุดอยู่ตรงไหน และเป็นร้านแบบไหน** — เดโมแผนที่ 3 มิติของชุดข้อมูล Restaurants ของ CityMETER ที่อ่านร้านอาหาร 70,214 ร้านใน 7 จังหวัดเป็นความหนาแน่นระดับแขวง/ตำบล พร้อมประเภทร้าน ระดับราคา เครือร้าน และที่มาของทุกตัวเลข — รุ่น 0.3 เพิ่มทะเบียนร้านเครือทั่วประเทศ (ชุดแยก นับคนละหน่วย) และร้านที่จุดตกในอาคารของศูนย์การค้า โรงแรม และอาคารสำนักงานในทะเบียน Land

- เว็บ: https://montri-th.github.io/restaurant/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=restaurant
- รุ่น 0.3.4 · 28 ตุลาคม 2569 (ร้าน 7 จังหวัดกับสาขาร้านเครือบนแผนที่เดียวกัน ไม่แยก tab · สาขาเป็นรูปหมุด ปิด/เปิดด้วยปุ่ม “ร้านเครือ”) (ข้อมูลร้านจากชีต 1 + แถวที่ย้ายไปทะเบียนร้านเครือ · ทะเบียนร้านเครือทั่วประเทศ · ตรวจ spatial join กับชุดข้อมูลกลุ่ม Land · รูปทรงอาคาร LOD2 เมื่อมี) · ร้านดึงและตรวจกับ API 22 ตุลาคม 2569 · ทะเบียนร้านเครือตรวจ 25–28 ตุลาคม 2569

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **99.7 ร้าน/ตร.กม. ใน 3 แขวงที่แน่นที่สุด — สี่แยกมหานาค ตลาดน้อย สุริยวงศ์** เทียบ 18.0 ร้าน/ตร.กม. ของทั้งพื้นที่ที่มีข้อมูล (308 แขวง/ตำบล) จัดอันดับเฉพาะพื้นที่ที่มีอย่างน้อย 30 ร้าน

> ชุดข้อมูล CityMETER Restaurants · แหล่ง CityMETER Restaurants API สาธารณะ · ดึงข้อมูล 22 ต.ค. 2569 · ขอบเขต แขวง/ตำบลของ CityMETER ใน 7 จังหวัด — ไม่ใช่สำมะโนร้านอาหาร คะแนนและรีวิวเป็นตัวชี้ความนิยมตามแหล่งข้อมูล ไม่ใช่ยอดขาย

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ การเปิด `index.html` เป็นไฟล์จะพาไปเว็บสาธารณะ

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** หน้าแรกโฟกัส 3 แขวง/ตำบลที่ร้านแน่นที่สุด (ร้าน/ตร.กม.) ส่วนอื่นของเมืองเป็นบริบทที่เงียบ — “ดูทุกพื้นที่” เปิดทุกพื้นที่เท่ากัน
- **เส้นทางพื้นที่แบบ production:** ประเทศไทย › จังหวัด › เขต/อำเภอ › แขวง/ตำบล ทุกระดับลิงก์ไปพื้นที่เดียวกันใน CityMETER (`/v3/citymeter/{จังหวัด}/D/{เขต}` · `/S/{แขวง}`)
- **สีพื้นที่:** ความหนาแน่น LDS `density.area` 5 ระดับเท่าช่วง (ช่วงตัวเลขในคำอธิบายแผนที่) · ลายทแยง = แหล่งข้อมูลไม่มีร้านในพื้นที่ (ไม่ใช่ศูนย์) · เมื่อซูมออกทั้งประเทศ จังหวัดที่มีข้อมูลมีกรอบและจำนวนร้าน
- **ร้าน:** 1 สัญลักษณ์ = 1 ร้าน สีและรูปทรงตามประเภทร้าน (LDS series พร้อมรูปทรงประจำ) ร้านนอกโฟกัสเป็นจุดสีเทา ซูมใกล้จะเห็นโลโก้เครือร้านและเลือกร้านด้วยเมาส์หรือคีย์บอร์ดได้
- **โปรไฟล์:** แขวง/ตำบลและเขต/อำเภอ (ร้าน ร้าน/ตร.กม. รีวิว คะแนนเฉลี่ย ประเภท ราคา รีวิวมากที่สุด เครือร้าน สถานที่ที่ชื่อร้านอ้างถึง) · ร้าน (คะแนน ราคา เครือ สถานที่ พิกัดแสดงผลและความแม่น ที่มา)
- **สถานที่:** จับจากชื่อร้าน — ชื่อที่อ้างถึงสถานที่ ชื่อที่ลงท้ายด้วยชื่ออาคาร/ตลาด/ศูนย์การค้า และ “สถานที่จากชื่อร้าน” เมื่อชื่อลงท้ายเหมือนกันหลายร้านในรัศมี 200 ม. · 26 แห่งมีข้อมูลอาคาร 3 มิติสีน้ำเงินที่มองเห็นเสมอ (venue x-ray) และ “มุมสถาปนิก” (เอ็ม บี เค เซ็นเตอร์ได้ส่วนอาคาร LOD2 จากทะเบียนศูนย์การค้าด้วย uuid ของ CityMETER)
- **อาคาร:** จุดของร้านจับกับอาคารที่แผนที่วาด (“จุดตกในอาคาร” ละเอียดราว 9.55 ม.) อาคารของสถานที่ในพื้นที่ที่โฟกัสเป็นสีน้ำเงิน กดอาคารเพื่อเปิดสถานที่ ร้าน หรือรายการร้านที่จุดตกในอาคารนั้น
- **ย้ายพื้นที่:** กดแขวง/ตำบลใดก็ได้บนแผนที่ (หรือป้ายของมัน) เพื่อย้ายไป ทุกระดับซูม
- **กราฟและตาราง:** ความหนาแน่น · ประเภทร้าน (matrix ช่องเท่ากัน) · ระดับราคา (เฉพาะร้านที่ระบุราคา) · ตารางร้านเรียงตามรีวิว
- **ร้านเครือ · ทั่วประเทศ (ใหม่ 0.3; แผนที่เดียวกับร้านตั้งแต่ 0.3.1):** จุดสาขาขึ้นบนแผนที่เดียวกับร้านตั้งแต่ซูมระดับเมือง เปิดทะเบียนจากภาพรวม แผงพื้นที่ หรืออาคาร Land — ทะเบียนร้านเครือ 26,819 สาขาในทะเบียน 755 เครือ (ไม่นับ Five Star network ซึ่งเป็นทะเบียนจุดขายหลายแบรนด์) 311 บริษัท/บทบาท ค้นหาเครือหรือบริษัท ดูสาขาตามจังหวัด หลักฐาน (แหล่งของแบรนด์ / แหล่งรอง / รถเข็น) และสถานะที่แหล่งระบุ กดจุดเพื่อเปิดสาขา (1 จุด = 1 สาขาที่มีพิกัด 16,728 จุด) — **นับคนละหน่วยกับร้านในชุดข้อมูล จึงไม่นำมาบวกกัน** แขวง/ตำบลและเขต/อำเภอแสดงเครือที่มีจุดสาขาในพื้นที่ และร้านที่ย้ายไปทะเบียนบอกสถานะในหน้าร้าน
- **อาคารในทะเบียน Land (ใหม่ 0.3):** ศูนย์การค้าและสถานที่ค้าปลีก โรงแรม และอาคารสำนักงาน — เปิดจากรายการในแผง ร้าน หรือสาขาที่จุดตกในอาคาร แผงเทียบประเภทร้านในอาคารกับรอบอาคาร 100 ม. และแสดงสาขาเครือในอาคาร รูปทรงใช้แบบละเอียด (ส่วนอาคาร LOD2) เมื่อทะเบียนมี — “จุดตกในอาคาร” ไม่ได้ยืนยันว่าร้านตั้งอยู่ในอาคาร
- **ตัวกรอง:** ค้นหา · ประเภทร้าน · ระดับราคา · จังหวัด · เครือร้าน — ทุกสถานะอยู่ใน URL (`search`, `group`, `price`, `province`, `brand`, `district`, `area`, `areas`, `view`, `store`, `place`, `view3d`, `cam`, และ `chains`/`rq`, `chain`, `company`, `outlet`, `land`)
- **ธีม:** Auto / Light / Dark — สีข้อมูลเป็น HEX เดียวกันทั้งสองธีมตาม LDS 0.9.7

## Data and method

- หนึ่งแถว = หนึ่ง observation ของร้านใน overlay สาธารณะของ CityMETER (`data/restaurants.json`, 70,214 แถว = ชีต 1 68,980 แถว + 1,234 แถวที่เจ้าของย้ายไปทะเบียนร้านเครือเมื่อ 25 ต.ค. 2569 นับครั้งเดียว) ตรวจกับการดึงใหม่จาก API ตรงกันทุกแถวทุก field
- ทะเบียนร้านเครือ (`data/chains.json`) นับหนึ่ง outlet_id ต่อสาขา/จุดขายที่มีหลักฐาน — ไม่ใช่จำนวนร้านที่เปิดจริง และไม่บวกกับจำนวนร้านในชุดข้อมูล จังหวัดได้จากจุดของสาขา (หรือข้อความจังหวัดในทะเบียน) แขวง/ตำบลเฉพาะ 7 จังหวัดที่ครอบคลุม
- จุดของร้านและสาขา × อาคาร Land (`data/land.json`, `data/land-buildings.geojson`): ในขอบอาคาร / ติดขอบ ≤ 10 ม. — อาคาร = รูปทรงที่ทะเบียนตรวจแล้ว (ส่วนอาคาร LOD2 เมื่อมี) หรือ footprint V4 ของ CityMETER production ที่จุดของสถานที่ ผลตรวจทั้งหมดใน [docs/LAND_JOIN_CHECK.md](docs/LAND_JOIN_CHECK.md)
- ความเป็นสมาชิกพื้นที่คือรหัสแขวง/ตำบลของต้นทาง ความหนาแน่น = ร้าน ÷ ตร.กม. ของ production
- พิกัดเป็นตำแหน่งแสดงผล (MVT z10, กริด 9.55 ม.) ไม่ใช่ทางเข้าร้าน
- เครือร้าน (169) และสถานที่ (1,100: ลิงก์ในชีต 1,016 + สถานที่จากชื่อร้าน 84) จับคู่จากชื่อร้าน — ไม่ได้ยืนยันความเป็นสาขาหรือที่ตั้งภายใน การจับจุดกับอาคารเป็นผลตอนแสดงผล ไม่เปลี่ยนตัวเลขใด
