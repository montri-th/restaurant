# Product Brief — CityMETER · Restaurants 0.2

รุ่น 0.2.1 · 23 ตุลาคม 2569 · ข้อมูลดึงและตรวจ 22 ตุลาคม 2569 (สร้างซ้ำ 23 ต.ค. ด้วยกติกาสถานที่ใหม่ ชุดร้านเดิม) · คู่กับ [product-brief.json](product-brief.json) (schema 1.4.0) · winning strategy อยู่ใน [../PRODUCT_STATEMENT.md](../PRODUCT_STATEMENT.md)

## 1. งานของผลิตภัณฑ์

คัดกรองและเปรียบเทียบแขวง/ตำบลด้วยความหนาแน่นของร้านอาหาร ประเภท ระดับราคา และเครือร้าน ก่อนตัดสินใจเรื่องทำเล โดยทุกตัวเลขบอก dataset · source · date · boundary

คำถามหน้าแรก: **ร้านอาหารแน่นที่สุดอยู่ตรงไหน และเป็นร้านแบบไหน**

ผู้ใช้ (Hypothesis): ทีมขยายสาขาและแฟรนไชส์ร้านอาหาร · ทีม leasing/asset ของศูนย์การค้าและอาคารพาณิชย์ · นักวิเคราะห์ ที่ปรึกษา และหน่วยงานท้องถิ่น

เส้นทาง: 3D first Aha → โปรไฟล์แขวง/ตำบล → เขต/อำเภอ → ร้าน → สถานที่พร้อมอาคาร → กดอาคารในโฟกัส (สถานที่ · ร้าน · ร้านที่จุดตกในอาคารนี้) → กดแขวง/ตำบลข้าง ๆ เพื่อย้ายไป → กราฟ/ตาราง → เปิดพื้นที่เดียวกันใน CityMETER production

## 2. สิ่งที่เปลี่ยนจากฐาน Luxury Brands 0.5

คงสัญญาเดิม: กล้อง (city/model/eye/plan), basemap กระดาษ, มวลอาคาร quiet/focus, venue x-ray, pictogram, launch/error paths, handoff + manifest + verify-live

ใหม่สำหรับร้านอาหาร: พื้นที่ปกครองของ production (แขวง/ตำบล, เขต/อำเภอ) แทนย่านที่นิยามเอง · ตัวชี้วัดความหนาแน่น + เกณฑ์ 30 ร้าน · สถานะความครอบคลุม (no_data ≠ measured_zero) · สัญลักษณ์ประเภทร้านบนแผนที่พร้อมรูปทรง LDS · family `price` · provenance ท้ายทุกมุมมอง · เครือ/สถานที่เป็น candidate จากชื่อ

รุ่น 0.2 (เจ้าของสั่ง 23 ต.ค. 2569; 0.2.1 = 0.2.0 + แก้จากการตรวจบนเว็บจริง): สถานที่จากท้ายชื่อร้าน (ชื่อในชีต + สถานที่จากชื่อร้านที่ลงท้ายซ้ำกันในรัศมี 200 ม.) · จับจุดของร้านกับอาคารที่แผนที่วาด (spatial join ตอนแสดงผล “จุดตกในอาคาร”) · อาคารของสถานที่แสดงและกดได้ในมุมมองพื้นที่ ทุกอาคารในโฟกัสกดได้ · กดแขวง/ตำบลข้าง ๆ ได้ทุกระดับซูมพร้อมป้ายของพื้นที่บนจอ จุดบริบทไม่ใช่เป้ากด · เลื่อนกล้องลื่นขึ้น (ไม่ส่งจุดบริบทซ้ำ มวลอาคารคำนวณหลังกล้องหยุด หมุดเกาะแผนที่ระหว่างเคลื่อน)

## 4. First Aha

- **Ranking:** แขวง/ตำบลที่มี ≥ 30 ร้าน เรียงตามร้าน/ตร.กม. (พื้นที่ production) → ร้าน → รหัส; 3 อันดับแรก
- **ข้อความ:** “{ความหนาแน่น} ร้าน/ตร.กม. — ร้านอาหารแน่นที่สุดใน 3 {แขวง|ตำบล|พื้นที่}นี้” + ชื่อพื้นที่ (ลิงก์) + ร้านและ ตร.กม. รวม + ฐานเทียบ “ทั้งพื้นที่ที่มีข้อมูล” + รีวิวมากที่สุด + เกณฑ์ 30 ร้าน
- **สูตร:** Σร้าน ÷ Σตร.กม.; ฐานเทียบ = ร้านทั้งหมด ÷ ตร.กม. ของแขวง/ตำบลที่มีข้อมูลในจังหวัด/เขตที่กรอง
- **Snapshot (fixture):** 100204 · 101303 · 100403 = 40 + 39 + 57 = 136 ร้าน / 1.365 ตร.กม. = 99.7; ฐานเทียบ 18.0 (308 พื้นที่, 3,899.1 ตร.กม.); รีวิวมากที่สุด 103902 (217,736)
- **Actions:** ดูทุกพื้นที่ · เปรียบเทียบพื้นที่; เมื่อโฟกัสปิด: โฟกัส 3 แขวงนี้
- **Fallbacks:** ไม่มีร้าน → ล้างตัวกรอง; < 1,000 ร้านหรือพื้นที่ผ่านเกณฑ์ < 3 → ข้อค้นพบแบบสัดส่วน “x% ของร้านตามตัวกรองอยู่ใน 3 พื้นที่นี้”; แผนที่ล้ม → แผง กราฟ ตารางยังใช้ได้

## 6. สัญญาความครอบคลุม (EVID-05)

- **measured:** สีระดับความหนาแน่น
- **measured_zero:** แขวง/ตำบลที่มีร้านในชุดข้อมูลเต็มแต่ 0 ตามตัวกรอง → สีระดับต่ำสุด + เส้นขอบศูนย์ 2 px (`dataState.zero`)
- **no_data:** แขวง/ตำบลที่ไม่มีร้านในชุดข้อมูลเลย (273/581) → ลายทแยง 135° บน `dataState.noData` + `border.emphasis` คำอธิบาย “ไม่มีข้อมูล — แหล่งข้อมูลไม่มีร้านในพื้นที่นี้ ไม่ได้แปลว่าไม่มีร้านอาหาร”
- **out_of_scope:** จังหวัดที่ไม่มีร้าน (70) → ไม่วาด

## 7. สัญญาแผนที่ focus/quiet

| สถานะ | Focus | Quiet |
|---|---|---|
| overview auto | 3 แขวง: สี ป้ายหมึก (ค่า + สี่เหลี่ยมสีระดับ) สัญลักษณ์ประเภท มวลอาคารมุมโค้ง | พื้นที่อื่นเป็นเส้นขอบ ป้ายอ่อน ≤ 12 (มือถือไม่มี) จุดเทา มวลเมืองจาง |
| overview all | ทุกพื้นที่มีสี ป้าย ≤ 30 (มือถือ 10) | — |
| เขต/อำเภอ | แขวง/ตำบลในเขตมีสี เส้นเขตเลือก | พื้นที่อื่นเส้นขอบ |
| แขวง/ตำบล | สีของแขวง (ถึง zoom 14.5) เส้นเลือก สัญลักษณ์ หมุด HTML + โลโก้จาก zoom 15.5 อาคารของสถานที่ที่ชื่อร้านในโฟกัสอ้างถึงเป็นสีน้ำเงิน ทุกอาคารในโฟกัสกดได้ | พื้นที่อื่นเส้นขอบ ทุกแขวง/ตำบลบนจอมีป้ายที่จุดมองเห็นได้ (≤ 16 · มือถือ 4) กดเพื่อย้ายไป |
| ร้าน | วงเลือก เส้นนำไปตำแหน่งแสดงผล popup (desktop) | ตามโฟกัสเดิม |
| สถานที่ | เฉพาะร้านที่ชื่ออ้างถึงสถานที่ มวลอาคารโฟกัสตามรอบสถานที่ อาคารสีน้ำเงิน: ข้อมูลอาคารของสถานที่ผ่าน x-ray + มุมสถาปนิก หรืออาคาร OSM ที่จุดของร้านตกอยู่ | ทุกอย่างอื่น |
| อาคาร | อาคารที่กด (สีน้ำเงิน) และร้านที่จุดตกในอาคารนั้น กล้องอยู่ที่เดิม | ทุกอย่างอื่น |

สัญลักษณ์: symbol layer ของ cue icon (สี series + รูปทรง + เส้นขอบ marker) สำหรับร้านในโฟกัส วางบนจุดวงกลมสีเทาของทุกร้านใน selection (บริบท — ส่งใหม่เมื่อเปลี่ยนตัวกรองเท่านั้น ไม่รับการกดและไม่อยู่ในลำดับ tab ครั้งแรกที่มี > 5,000 จุด ส่งช้าลง 0.9 วินาที)

การกดบนแผนที่ตามลำดับ: ตัวอาคารของสถานที่ (x-ray) → อาคารของสถานที่ → หมุดในโฟกัส → อาคารในโฟกัส (อาคารของสถานที่ → สถานที่ · จุดเดียว → ร้าน · หลายจุด → แผงอาคาร · ไม่มีจุด → ผ่านไป) → กรอบจังหวัด (ซูมระดับประเทศ) → แขวง/ตำบล (`area-hit` ทุกระดับซูม) กดในพื้นที่ที่เลือกอยู่แล้วไม่เปลี่ยนอะไร เมาส์ชี้พื้นที่อื่นแสดงเส้นขอบบาง ๆ ของพื้นที่ที่จะเปิด

## 9. Breadcrumb และลิงก์ production

ประเทศไทย › จังหวัด › เขต/อำเภอ › แขวง/ตำบล ด้วยรหัสของ production: จังหวัด `BKK NBI SPK PTE SKN CCO NPT`, เขต/อำเภอและแขวง/ตำบลตามรหัส DOPA ลิงก์ลึก `https://landometer.com/v3/citymeter/{code}[/D/{เขต}|/S/{แขวง}]?d=restaurant` (Observed fact จาก bundle ของ production, ตอบ HTTP 200 วันที่ 22 ต.ค. 2569) โหมดสถานที่: ประเทศไทย › จังหวัด › สถานที่ ร้านเป็นหัวข้อแผง ไม่ใช่ crumb

## 10. แผงอ่านหกโหมด

overview · district · area · venue · building · store พร้อม back stack (20) และ URL (`district`, `area`, `place`, `store`; แผงอาคารไม่อยู่ใน URL — โหลดใหม่กลับไปที่พื้นที่) ทุกโหมดจบด้วยบรรทัดที่มา: “ชุดข้อมูล CityMETER Restaurants · แหล่ง CityMETER Restaurants API สาธารณะ · ดึงข้อมูล 22 ต.ค. 2569 · ขอบเขต …” + “ร้าน = รายการในชุดข้อมูล … คะแนนและรีวิวบอกความนิยมตามแหล่งข้อมูล ไม่ใช่ยอดขาย”

รายการพื้นที่: พื้นที่ ≥ 30 ร้านมีอันดับและแท่งความหนาแน่น พื้นที่น้อยกว่านั้นแสดงต่อท้ายโดยไม่มีอันดับ เมื่อไม่มีพื้นที่ใดผ่านเกณฑ์ เรียงและวาดแท่งตามจำนวนร้าน

## 11. กราฟ

| มุมมอง | คำถาม | การเข้ารหัส |
|---|---|---|
| `density` ความหนาแน่น | แขวง/ตำบลไหนร้านแน่นที่สุด | แท่งเรียงลำดับ สีระดับ density (แท่งจำนวนเมื่อการเลือกเล็ก) |
| `mix` ประเภทร้าน | พื้นที่ที่แน่นที่สุดมีร้านประเภทไหน | matrix ช่องเท่ากัน สี count หัวคอลัมน์มีรูปทรง |
| `price` ระดับราคา | พื้นที่เหล่านั้นราคาระดับไหน | แท่งซ้อน 100% ของร้านที่ระบุราคา ไม่ระบุนับแยก |

## 12. เครือร้าน สถานที่ และโลโก้

เครือ 167 (3 รอยืนยันตัวตน) และสถานที่ 1,100 รายการเป็น candidate จากชื่อร้าน — ข้อความ “ร้านอื่นที่ชื่อตรงกับ…” และ “ชื่อร้านอ้างถึงสถานที่นี้” / “ชื่อร้านลงท้ายด้วยชื่อสถานที่นี้” / “สถานที่จากชื่อร้าน” เท่านั้น สถานที่มาจาก 3 ขั้น (`venueMatchContract`): ลิงก์ในชีต 1,016 · ชื่อหรือชื่อเรียกอื่นในชีตอยู่ท้ายชื่อร้าน 11 แถว (เช่น “KFC Gateway Bangsue”) · คำลงท้ายแบบชื่อสถานที่ที่ซ้ำ ≥ 2 ชื่อและทุกจุดอยู่ในรัศมี 200 ม. จากจุดกลาง 84 แห่ง 252 แถว (เช่น Charn At The Avenue 14 ร้าน) คำว่า หน้า/ข้าง/ตรงข้าม/near/behind ก่อนชื่อสถานที่ไม่นับ (41 แถว) โลโก้ 155 + 157 ไฟล์คงไบต์เดิม (sha256) ค้นด้วย id พื้นรองจาก registry โลโก้ร่วม/แม่มีคำบอกบทบาท บนแผนที่ ≤ 250 โลโก้และเฉพาะ zoom ≥ 15.5 ในโฟกัส อาคารของสถานที่ 25 แห่งจับคู่ชื่อตรงตัวกับชุดอาคารของ Luxury Brands

จุดของร้าน × อาคาร (`buildingJoinContract`, INV24): จุดแสดงผล (กริด 9.55 ม.) จับกับขอบอาคารที่แผนที่วาด — อาคาร OSM ในส่วนโฟกัส (ขอบเดิมก่อนทำมุมโค้ง) และอาคารของสถานที่ ใช้คำว่า “จุดตกในอาคาร” เสมอ ไม่เปลี่ยนแถวหรือจำนวนของสถานที่ ร้านที่จุดตกในอาคารเดียวกันแต่ชื่อไม่ได้อ้างถึงแสดงแยกเป็น “ร้านอื่นที่จุดตกในอาคารเดียวกัน” อาคารของสถานที่บนจอ = ข้อมูลอาคารของสถานที่ หรืออาคาร OSM ที่มีจุดของร้านซึ่งชื่ออ้างถึง ≥ max(1, ⌈20 %⌉)

Observed fact: 18 สถานที่มีแถวที่เป็นชื่อสถานที่เองในชุดร้าน (Shopping Mall 12, Hotel 5, Food Court 1) เช่น “Central Pinklao” (Shopping Mall) มี 24,563 จาก 30,900 รีวิวของ 12 แถวที่ชื่ออ้างถึงสถานที่นี้ เดโมคงแถวตามแหล่งข้อมูลและบอกส่วนนี้ใต้ตัวเลขของสถานที่
