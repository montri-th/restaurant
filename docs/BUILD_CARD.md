# CityMETER Restaurants — first useful value

Build Card ของสัญญาการใช้งานครั้งแรกของเดโมนี้ ใช้ LDS 0.9.7 release `v0.9.7-owner.1` เอกสาร standalone `lds-0.9.7-landometer-standalone-r1` SHA-256 `d3085cbc0a50195f1cbf0c77b1d77c0d19b84364daf2948eb367348d65432d96` ไม่ใช่ใบรับรองความสอดคล้องทั้งระบบหรือผลผ่านทุกเบราว์เซอร์

## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** ร้านอาหารในชุดข้อมูลแน่นที่สุดในแขวง/ตำบลใด และแน่นกว่าภาพรวมแค่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot 22 ต.ค. 2569): **“99.7 ร้าน/ตร.กม. — ร้านอาหารแน่นที่สุดใน 3 แขวงนี้”** สี่แยกมหานาค · ตลาดน้อย · สุริยวงศ์ — 136 ร้านใน 1.4 ตร.กม. เทียบ **18.0 ร้าน/ตร.กม.** ของทั้งพื้นที่ที่มีข้อมูล ข้อค้นพบรอง “รีวิวมากที่สุด: แขวงคลองตันเหนือ 217,736 รีวิว” และบอกเกณฑ์ “จัดอันดับเฉพาะพื้นที่ที่มีอย่างน้อย 30 ร้าน” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 แขวงนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth สัญลักษณ์ร้านตามประเภท โลโก้เครือ (เมื่อซูมใกล้) และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ (กรอบเส้น ป้ายอ่อน จุดสีเทา มวลอาคารจาง)

**One useful action:** “ดูทุกพื้นที่” (ยกโฟกัส, `?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) เมื่อโฟกัสปิดอยู่ ปุ่มกลายเป็น “โฟกัส 3 แขวงนี้” เมื่อเปลี่ยนตัวกรอง ข้อค้นพบ ตัวหาร และโฟกัสอัตโนมัติคำนวณใหม่ทั้งหมด

ข้อค้นพบเปิดในแผงอ่านก่อนตัวกรองใด ๆ (ตัวกรองพับอยู่ใน disclosure) บนจอแนวตั้งแคบ ข้อค้นพบและปุ่มเดียวกันแสดงในการ์ดบนแผนที่เหนือคำอธิบาย ขณะ bottom sheet ปิด ไม่มี onboarding modal ไม่มี decorative left rail หรือ bracket

## Evidence cue and calculation

แหล่ง: `data/restaurants.json` (70,214 แถว, `meta.asOf` 2026-10-22) และ `data/areas.geojson` (581 แขวง/ตำบล, `areaSqm` ของ production) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| แขวง | รหัส | ร้าน | ตร.กม. |
|---|---|---:|---:|
| สี่แยกมหานาค | `100204` | 40 | 0.358 |
| ตลาดน้อย | `101303` | 39 | 0.400 |
| สุริยวงศ์ | `100403` | 57 | 0.607 |

รวม 136 ร้าน ÷ 1.365 ตร.กม. = 99.7 ร้าน/ตร.กม. (ไม่เฉลี่ยอัตราส่วน) ฐานเทียบ 70,214 ร้าน ÷ 3,899.1 ตร.กม. ของ 308 แขวง/ตำบลที่มีร้าน = 18.0 ความเป็นสมาชิกพื้นที่คือรหัสแขวง/ตำบลของต้นทาง ไม่ใช่ point-in-polygon บนพิกัดแสดงผล ตัวเลขเป็นสัดส่วนเชิงพรรณนาภายในชุดข้อมูลนี้ ไม่ใช่ความครบของตลาด ยอดขาย หรือความต้องการ

API ของฟังก์ชัน: `{mode, minRows, areas, areaIds, count, km2, density, baselineDensity, coverageKm2, coverageAreas, ratio, share, totalRows, areaCount, eligibleCount, mostReviewed}` และ `filterAreaRows(rows, set)` คืนแถวเดิมตามลำดับเดิม ไม่แตะพิกัด

ถ้าตัวกรองไม่มีร้าน แสดง empty state “ไม่พบร้านตามตัวกรองนี้” พร้อมปุ่มล้างตัวกรอง ห้ามแปลงศูนย์เป็น “ไม่มีร้านอาหารที่นี่”

## Prerequisites and safe paths — AHA-01-A

- **จำเป็นสำหรับข้อค้นพบ:** `data/restaurants.json`, `data/areas.geojson`, `data/districts.geojson` โหลดและ parse ได้บน HTTP(S) เปิดเป็นไฟล์ในเครื่องจะถูกพาไปเว็บสาธารณะ (`js/launch.js`)
- **ไม่จำเป็น:** บัญชี ข้อมูลส่วนตัว ตำแหน่งผู้ใช้ สิทธิ์อุปกรณ์ การแชร์ ไลบรารีกราฟ WebGL tiles แผนที่ อาคาร หรือโลโก้
- แผนที่ (MapLibre จาก unpkg + tiles OpenFreeMap) โหลดแยก ถ้าล้มเหลว ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ และมีปุ่มลองโหลดแผนที่ใหม่
- ข้อมูลหลักโหลดไม่ได้ → หน้าแสดงสถานะ error พร้อม retry และลิงก์เว็บสาธารณะ ไม่แสดงตัวเลขว่าง
