# พื้นที่ ความหนาแน่น และข้อค้นพบแรก

เอกสารนี้อธิบายว่าทำไม CityMETER · Restaurants อ่าน “ร้านอาหารแน่นที่สุดอยู่ตรงไหน” ด้วยความหนาแน่นต่อแขวง/ตำบล และคำนวณข้อค้นพบแรกอย่างไร ตัวเลขเป็นค่าของ snapshot 22 ต.ค. 2569 (`data/restaurants.json → meta.asOf`) ใช้เป็น regression fixture ใน `tests/insight.test.js` ไม่ใช่ค่าคงที่ใน UI

## 1. หน่วยวิเคราะห์: แขวง/ตำบลของ CityMETER

- ใช้ขอบเขตแขวง/ตำบลของ production เพราะเป็นระดับที่ API นับร้านเอง (`ST_Contains` บนพิกัดต้นทาง) แถวทุกแถวมีรหัสแขวง/ตำบลของต้นทาง จึงไม่ต้องเดาความเป็นสมาชิกจากพิกัดแสดงผลที่ปัดกริด
- เส้นทางเดียวกับ production: ประเทศไทย › จังหวัด › เขต/อำเภอ › แขวง/ตำบล และลิงก์ลึก `/v3/citymeter/{จังหวัด}/D/{รหัสเขต}` · `/S/{รหัสแขวง}` (`js/breadcrumb.js`)
- ไม่ได้นิยามย่านเอง (ต่างจาก Luxury Brands) เพราะร้านอาหารกระจายทั่วเมือง และหน่วยปกครองทำให้เทียบกับข้อมูลอื่นของ CityMETER ได้ตรงไปตรงมา

## 2. ทำไมใช้ความหนาแน่น ไม่ใช่จำนวนร้าน

จำนวนร้านต่อแขวงลำเอียงตามขนาดพื้นที่: แขวงชานเมืองขนาดใหญ่มีร้านมากเพราะพื้นที่ใหญ่ ไม่ใช่เพราะร้านแน่น (Inference จากข้อมูล: แขวง/ตำบลที่มีร้าน 308 แห่งมีขนาดมัธยฐาน 7.3 ตร.กม. ช่วงเปอร์เซ็นไทล์ 10–90 คือ 1.0–32.3 ตร.กม.) จึงเลือก LDS family **`density.area`** (ตัวหาร = พื้นที่) หน่วย **ร้าน/ตร.กม.** ตามหลัก “เลือกสเกลตามความหมาย หน่วย ตัวหาร” ของ owner amendment และใช้ตัวหารเดียวกับหน้าสรุปของ production (พื้นที่ของพื้นที่ปัจจุบันเป็น ตร.กม.)

ยกเว้นกรอบจังหวัดในมุมมองประเทศ ซึ่งใช้ family **`count`** (ยอดรวม) เพราะนอก กทม. นนทบุรี และสมุทรปราการ แหล่งข้อมูลครอบคลุมเพียงบางตำบล ความหนาแน่นระดับจังหวัดจะวัดความครอบคลุมของข้อมูลมากกว่าความแน่นของร้าน

## 3. ข้อค้นพบแรก (AHA-01)

- **Ranking:** แขวง/ตำบลที่มีร้านตามตัวกรอง **อย่างน้อย 30 ร้าน** (`MIN_AREA_ROWS`) เรียงตามร้าน/ตร.กม. มาก→น้อย แล้วตามจำนวนร้าน แล้วตามรหัส เกณฑ์ 30 ร้านไม่ใช่น้ำหนัก แต่กันพื้นที่เล็กมากที่มีร้านไม่กี่ร้านไม่ให้ขึ้นอันดับด้วยความบังเอิญ (ความคลาดเคลื่อนสุ่มของการนับราว 1/√n ≈ 18% ที่ n = 30)
- **ตัวเลข:** ความหนาแน่นรวมของ 3 อันดับแรก = Σร้าน ÷ Σตร.กม. (ไม่เฉลี่ยอัตราส่วน)
- **ฐานเทียบ:** ร้านและสาขาที่มีกรอบในตัวกรอง (สาขาที่ไม่มีพิกัดหรืออยู่นอกกรอบอยู่ในยอดรวม ไม่อยู่ในฐานเทียบ) ÷ พื้นที่ที่ชุดข้อมูลครอบคลุม (แขวง/ตำบลที่มีร้านอย่างน้อย 1 แถวในชุดข้อมูลเต็ม ภายในจังหวัด/เขตที่กรอง)
- **ข้อค้นพบรอง:** แขวง/ตำบลที่มีจำนวนรีวิวรวมมากที่สุด (ตัวชี้ความนิยม ไม่ใช่ยอดขาย)
- **การเลือกที่เล็ก:** ถ้าตัวกรองเหลือน้อยกว่า 1,000 ร้าน หรือมีพื้นที่ผ่านเกณฑ์ไม่ถึง 3 แห่ง จะเปลี่ยนเป็นข้อค้นพบแบบจำนวน: “x% ของร้านตามตัวกรองอยู่ใน 3 พื้นที่นี้”

ค่าเริ่มต้น (Observed fact, ไม่กรอง, รุ่น 0.6 ประชากรเดียว = ร้านชีต 1 ตามรหัสแขวง + สาขาในทะเบียนที่จุดตกในกรอบ):

| แขวง | เขต | ร้าน (ร้าน + สาขา) | ตร.กม. | ร้าน/ตร.กม. |
|---|---|---:|---:|---:|
| สุริยวงศ์ (`100403`) | บางรัก | 80 (54 + 26) | 0.61 | 131.8 |
| สีลม (`100402`) | บางรัก | 184 (117 + 67) | 1.51 | 121.5 |
| วังใหม่ (`100702`) | ปทุมวัน | 158 (80 + 78) | 1.34 | 118.1 |
| **รวม 3 แขวง** | | **422** | **3.46** | **122.0** |
| ทั้งพื้นที่ที่มีข้อมูล (475 แขวง/ตำบล) | | 76,610 แถวที่มีกรอบ (จากประชากร 95,799) | 8,171.8 | 9.4 |

ข้อค้นพบรอง: แขวงคลองตันเหนือ (`103902`) มีรีวิวรวมมากที่สุด 214,826 รีวิว (รีวิวมีเฉพาะร้านในชุดข้อมูล)

รุ่น 0.5 บนร้านอย่างเดียว (70,214 แถวรวมแถวที่ย้าย): สี่แยกมหานาค 40/0.36 · ตลาดน้อย 39/0.40 · สุริยวงศ์ 57/0.61 = 136 ร้าน / 1.36 ตร.กม. = 99.7 เทียบ 18.0 (308 แขวง/ตำบล, 3,899.1 ตร.กม.) — เก็บไว้เป็นประวัติ

**ความไว (sensitivity, Inference):** ถ้ายกเกณฑ์เป็น 100 ร้าน 3 อันดับแรกจะเป็น ดาวคะนอง (80.1) สีลม (78.6) ปากคลองภาษีเจริญ (70.3) — แขวงเมืองเก่าที่ชนะในเกณฑ์ 30 ร้านไม่ได้ถูกตัดเพราะสุ่ม แต่เพราะพื้นที่เล็ก (n = 39–57 ร้านให้ความคลาดเคลื่อนราว ±13–16% ซึ่งยังสูงกว่าอันดับถัดไปชัดเจน) จึงคงเกณฑ์ 30 ร้านและแสดงเกณฑ์บนหน้าจอ

## 4. Choropleth และสถานะค่า

- สีแขวง/ตำบล = ระดับ `density.area` 5 ระดับเท่าช่วง (equal interval) จาก 0 ถึงค่าสูงสุดในตัวกรองที่ปัดขึ้น (`buildDensityClasses`); ช่วง [ล่าง, บน) ช่วงสุดท้ายปิด; ทศนิยมตามขนาดค่า (จำนวนเต็มตั้งแต่ 20 ร้าน/ตร.กม., ทศนิยม 1 ตำแหน่งตั้งแต่ 2, ทศนิยม 2 ตำแหน่งต่ำกว่านั้น) ช่วงตัวเลขอยู่ในคำอธิบายแผนที่เสมอ
- ใช้ LUT 41 ค่าของ LDS โดยตรง ระดับที่ i คือ LUT[round(i·40/4)] ไม่ interpolate ไม่มีสูตร dark — HEX เดียวกันทั้งสองธีม
- สถานะ: measured · measured_zero (มีร้านในชุดข้อมูลเต็มแต่ไม่มีตามตัวกรอง = สีระดับต่ำสุด + เส้นขอบศูนย์) · no_data (ไม่มีร้านในชุดข้อมูลเลย = ลายทแยง ไม่ใช่ 0) · out_of_scope (จังหวัดที่ไม่มีข้อมูล = ไม่วาด)
- ป้ายบนแผนที่แสดงชื่อ + ค่าร้าน/ตร.กม. + สี่เหลี่ยมสีระดับของพื้นที่นั้น (ลิงก์กับคำอธิบาย) ป้ายในโฟกัสเป็นชิปหมึก ป้ายนอกโฟกัสเป็นชิปอ่อน
- สีข้อมูลหยุดที่ zoom 14.5 (hard switch) จากนั้นสัญลักษณ์ร้าน โลโก้ และอาคารรับหน้าที่อ่าน

## 5. สิ่งที่ตัวเลขไม่ได้บอก

ความหนาแน่นของ observation ในชุดข้อมูลนี้ ไม่ใช่: จำนวนร้านอาหารทั้งหมดของพื้นที่, ความต้องการของลูกค้า, ยอดขาย, การแข่งขันที่รุนแรง หรือโอกาสทางธุรกิจ (ทราฟฟิกสูง ≠ โอกาสอาหารสูง) ตัวหารเป็นพื้นที่ทั้งตำบลรวมพื้นที่ที่ไม่ใช่ย่านการค้า การตัดสินใจเรื่องทำเลต้องตรวจภาคสนามและข้อมูลชั้นอื่นประกอบ
