# CityMETER Restaurants — owner preferences

Set 2026-10-22 (release 0.1), carried over from CityMETER · Luxury Brands 0.5 where the same contract applies.

- Apply current LDS 0.9.7 (v0.9.7-owner.1, standalone-0.9.7-r1) and preserve the map-first CityMETER layout. Colours come only from `assets/theme.css`, `js/scales.js` and `js/cues.js`; never approximate a value by eye. Analytical colours are the same HEX on both themes; EVID-05 map treatments use the `dataState` tokens (`--data-no-data`, `--data-zero-outline`).
- Read `PRODUCT_STATEMENT.md` before changing what the first screen argues. The question is “ร้านอาหารแน่นที่สุดอยู่ตรงไหน และเป็นร้านแบบไหน”.
- Aha first, in 3D: the first paint is the `city` preset framing the three densest แขวง/ตำบล (≥ 30 rows, restaurants per km² of the production area), focused automatically (`auto`, no `areas` param). Show the combined density (Σrows ÷ Σkm²), the coverage baseline, the eligibility rule and the actions (ดูทุกพื้นที่, เปรียบเทียบพื้นที่) before filters. Snapshot numbers in the handoff JSON are fixtures, never UI constants.
- Metric choice is a contract: density (`density.area`, ร้าน/ตร.กม.) for แขวง/ตำบล and เขต/อำเภอ; totals (`count`) for province frames and matrix cells; `price` for price buckets. Never rank areas by density below the eligibility threshold; small selections switch to counts and say so.
- Membership is the row's own source subdistrict code (`cols.area`); never re-assign by point-in-polygon on display coordinates or by name. District and province come from that subdistrict.
- Coverage is a fact: a subdistrict with no row in the full dataset is `no_data` (hatch), a covered subdistrict with no row under the filter is `measured_zero`; provinces without rows are `out_of_scope` (not drawn). Never show missing as zero; ratings/reviews/prices that are absent stay absent.
- Focus + quiet context: detail (fills, coloured cue symbols, logos, rounded focus massing) only for the focused part — the selected area, the district, the automatic or explicit focus, or a venue. Everything else stays visible but quiet: outline-only areas, light label chips, grey context dots outside the tab order, quiet city massing.
- Food-type groups bind by stable id to LDS series with the series shape cue (`js/cues.js#GROUP_SERIES`; DATAVIZ-05). Never colour a category by hue alone; keep the cue in legends, lists, matrix headers and map symbols.
- Brand (chain) and venue links are name-based candidates (`meta.brandRule`, `meta.venueRule`). Say “ร้านอื่นที่ชื่อตรงกับ…”, never “สาขา”; say “ชื่อร้านอ้างถึงสถานที่นี้”, never “ตั้งอยู่ใน”. A venue is never a crumb under a แขวง. No proximity inference for membership (the display-time building join of 2026-10-23 is labelled “จุดตกในอาคาร” and never changes a venue's rows).
- Breadcrumb is ประเทศไทย › จังหวัด › เขต/อำเภอ › แขวง/ตำบล with production codes (`js/model.js#PROVINCES`, DOPA district/subdistrict codes) and deep links `/v3/citymeter/{code}/D/{district}` · `/S/{subdistrict}` `?d=restaurant`. Venue mode reads ประเทศไทย › จังหวัด › venue. A store is the panel heading, never a crumb.
- Every panel view ends with dataset · source · date · boundary (`provenance()` in `js/panel.js`) and the popularity caveat. Keep generic caveats and research residue out of popups, tooltips and help otherwise.
- Basemap, massing, camera, host buildings and venue x-ray follow the Luxury Brands contracts (with the 2026-10-23 additions below: massing venue tier, footprints, stable ids, host buildings at area level) (`js/map-style.js`, `js/massing.js`, `js/camera.js`, `js/buildings.js`, `js/venue-xray.js`): basemap tokens only, OSM heights are context, presets never move data, keep every 3D preset at pitch ≤ 90° − fov/2 − 3°, install the host extrusion before every massing tier and let the x-ray draw the venue on top.
- One symbol always represents one observation; never cluster or aggregate. HTML pins from zoom 15.5 inside the focus only (≤ 320), logos ≤ 250, quiet context dots are never focusable or clickable.
- Logos: lookup by brand/venue candidate id only, original bytes (sha256 in the registries), backplate from the registry, identity holds get no logo, shared/parent venue marks keep their role caption. Collecting files is not a trademark licence.
- Copy: short, natural Thai — ร้าน / เครือร้าน / สถานที่ / แขวง·ตำบล / เขต·อำเภอ; units on every number (ร้าน, ร้าน/ตร.กม., รีวิว, บาท).
- Charts: matrix cells are equal in size; the stacked price bar is a share of priced rows only. No CSV download. No decorative brackets or coloured left rails. Visible focus everywhere.
- Never commit the internal research sheet, private Drive/Sheet URLs, credentials or the full LDS library. Review Thai at desktop and 390 px in light and dark before claiming done; local renders are not proof of a live release — run `npm run verify:live`.
